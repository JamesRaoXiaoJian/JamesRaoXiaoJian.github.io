你好，我是饶小建，也可以叫我 James。在深圳大学读计算机，最近主要在做机器人。

平时的工作大概是：采数据、跑仿真，再把模型放到真实的机械臂和灵巧手上试一试。我比较关心模型到了真机上会怎样，以及数据和控制过程中那些容易被忽略的小问题。

最近在做这几个项目：

- [sim2real_g1](https://github.com/JamesRaoXiaoJian/sim2real_g1)：在 G1 的双臂和灵巧手上部署、评估策略模型。
- [TransVTLA-RealDataCollect](https://github.com/JamesRaoXiaoJian/TransVTLA-RealDataCollect)：一起采集 RGB-D、触觉和机器人状态，整理成训练数据。
- [LEAP-DexRetarget](https://github.com/JamesRaoXiaoJian/LEAP-DexRetarget)：把人手动作映射到灵巧手上，目前在做重定向和仿真验证。

也做了一个和机器人无关的项目：[SV_Soul](https://github.com/JamesRaoXiaoJian/SV_Soul)，给《星露谷物语》的 NPC 加上能记住聊天内容、了解游戏状态的 AI 对话。

项目相关的问题可以直接提 issue，也欢迎来聊机器人、数据，或者游戏里的 AI。
